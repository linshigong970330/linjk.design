关于我

Designer / 2019 - Present

你好，我是 LinJK 👋

毕业于视觉传达专业，拥有 6 年设计行业经验。目前专注于品牌活动视觉系统、商业美陈、 企业展厅与空间方案设计，擅长用视觉语言将商业策略与艺术美学融合， 为品牌创造真正有记忆点的视觉体验。

无论是一张海报的字体排印，还是一个上千平展厅的空间叙事， 我都以同样的专注度投入其中 —— 我相信好设计藏在细节里。

服务内容

我能为你做什么

活动平面设计

品牌发布会、论坛峰会、节庆活动等全案主视觉设计，涵盖海报、背景板、邀请函、导视物料等全套延展。

  • 主视觉 KV
  • 活动物料延展
  • 印刷品 / 数字物料

商业美陈设计

购物中心季节性美陈、品牌 DP 点、快闪店、装置艺术等，从概念方案到施工图落地全流程支持。

  • 季节 / 节日美陈
  • 快闪店 / 中庭装置
  • DP 打卡点

展厅空间设计

企业展厅、文博展馆、临展展台、销售中心等室内空间方案设计，含平面布局、效果图、多媒体展项建议。

  • 企业品牌展厅
  • 博物馆 / 文化馆
  • 展览展台

三维建模渲染

空间方案效果图、产品建模、装置艺术表现等，熟练使用 3ds Max / C4D / Blender 多种渲染器。

  • 空间效果图表现
  • 产品建模渲染
  • 3D 动画（可谈）
