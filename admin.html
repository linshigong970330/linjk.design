① 一键发布到站点

把你当前 Admin 里所有作品 + 个人信息打包为 site-data.json（固定文件名，不用改）。所有访问你网站的人（手机、HR 电脑）等你下一步发布后都会看到这份内容。

接下来 2 步搞定全网同步
  1. 把刚下载的 site-data.json 文件复制到：
    D:\个人作品网站\LinJK\public\site-data.json（public 文件夹就在项目根目录，自动随 build 打包）
  2. PowerShell 运行：
    cd d:\个人作品网站\LinJK ; npm run build-github
    得到 dist-github.zip → 解压后拖到 GitHub Upload files 覆盖旧文件。

② 导出备份（自己留档/迁设备）

导出一个带日期的 linjk-data-YYYYMMDD.json，用于备份留存或发到手机端 Admin 导入（自己的多设备迁移）。这个不要拿来发布。

从备份导入

从之前导出的 JSON 文件恢复数据（会覆盖当前 localStorage 中的自定义内容）。

一键恢复默认

清空你在 localStorage 中自定义的作品与文字内容，恢复网站初始的默认示例数据。

关于数据存储 & 发布（重要！）

  • 「在 Admin 改完 → 点保存」：只有你现在这台电脑这个浏览器立刻看到效果。其它电脑 / 手机 / HR 打开网址是看不到的。
  • 「让所有人（手机+HR）看到你的最新内容」的正确流程：改完作品/文字 → 点上面绿色「下载 site-data.json（发布用）」 → 复制到项目 public/site-data.json → npm run build-github → 上传新 zip 到 GitHub 覆盖。
  • 图片可上传本地文件（自动转 base64）或填写网络图片 URL，建议大图片压缩后再上传，避免 site-data.json 太大（GitHub Pages 单文件一般建议 ≤25MB）。
  • 更换浏览器 / 清理浏览器缓存前，请先导出备份 JSON，否则 Admin 里的草稿会丢失。
